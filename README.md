"# WhatToCook-" 

WhatToCook? is a web/ mobile application that helps users to turn their current pantry into daily and weekly meal plans. This app allows the users to use their preferred input methods which includes a camera, voice and manual typing. The app features a system that suggests recipes based on the quantities, dietary preferences ,spoilage risk and also suggests the alternatives for the missing or spoiled items. It also comes with a guide that helps users to cook their selected dishes step-by-step on their current ingredients. This app is exclusively for Filipino dishes which only prioritize the local brand ingredient matches. The goal for this application is to focus on the convenience, waste reduction and practical meal planning.

Tools using for this app development:
Frontend - Ionic angular(mobile)
Backend - PHP/Laravel(web)
Database - MySQL
